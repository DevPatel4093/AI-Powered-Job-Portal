# AI Powered Job Portal

## Features

- JWT Authentication
- Role Based Access
- Candidate Dashboard
- Recruiter Dashboard
- Job Posting
- Job Application
- Resume Upload
- AI Match Score
- Missing Skills Detection
- Interview Scheduling
- Email Notifications

Authentication:
